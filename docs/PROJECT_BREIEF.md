# Project Brief: Lazy but Busy

## Brand Essence
**Name:** Lazy but Busy  
**Slogan:** Lazy by Nature. Busy by Choice.  
**Mission:** To weaponize laziness into peak efficiency. We build software that automates the mundane so humans can get back to what they do best: absolutely nothing.

## Visual Identity
*   **Theme:** "Efficient Paradox" — A high-contrast, neobrutalist aesthetic using a strict black-and-grey palette.
*   **Style:** Bold borders, chunky offset shadows, grid-based layouts, and generous whitespace.
*   **Typography:** Space Grotesk (Oversized headings, bold weights) for a playful yet engineered look.
*   **Mascot:** A programmer sloth, typically seen in an ergonomic chair with a laptop, embodying the "Relaxed Productivity" vibe.

## Core Philosophy
1.  **Hard work is a bug, not a feature.** If it can be automated, it should be.
2.  **The "Eh, Good Enough" Protocol.** Perfectionism is the enemy of a good nap.
3.  **Nap-Driven Development.** We ship working, rugged code so we can go home early.

## Site Structure (Desktop)
1.  **Home:** High-impact hero section featuring the sloth mascot and a manifesto of "optimized laziness."
2.  **Our Vibe:** A deep dive into the company culture, comparing "The Busy Way" (burnout) vs. "The Lazy Way" (nap time).
3.  **Tools:** Showcase of productivity anti-patterns (e.g., The Auto-Napper, Meeting Mutiny, Blame Generator).
4.  **The Lab:** A workspace for experimental, "possibly illegal" automation scripts and abandoned projects like Project "NOPE."
5.  **Manifesto:** (Planned) A full breakdown of our commitment to doing as little as possible.
