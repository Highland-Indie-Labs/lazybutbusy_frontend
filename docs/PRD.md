# Product Requirements Document: Lazy but Busy

## 1. Project Overview
**Product Name:** Lazy but Busy Website  
**Vision:** To be the digital home for "Relaxed Productivity"—software that automates the mundane so humans can do nothing.  
**Target Audience:** Different kinds of Business Owner,Burnt-out developers, automation enthusiasts, and fans of neobrutalist design.

---

## 2. Brand & Visual Identity
*   **Design System:** {{DATA:DESIGN_SYSTEM:DESIGN_SYSTEM_1}} (Efficient Paradox).
*   **Visual Style:** Neobrutalist (High contrast, bold borders, #000000 / #FFFFFF / Greyscale).
*   **Typography:** Space Grotesk (Oversized, bold).
*   **Key Asset:** Sloth Mascot (Programmer sloth in ergonomic chair).

---

## 3. Functional Requirements

### 3.1 Global Navigation
*   **Components:** `TopNavBar`, `Footer`.
*   **Links:** Our Vibe, Tools, The Lab, Manifesto.
*   **CTA:** "Hire Us (Maybe)" – Primary action button.

### 3.2 Core Screens
1.  **Home (Landing Page):**
    *   Hero section with Mascot and Manifesto snippet.
    *   Brief overview of "Nap-Driven Development."
    *   Links to sub-pages.
2.  **Our Vibe (Culture):**
    *   Comparison grid: "The Busy Way" vs. "The Lazy Way."
    *   Engagement metrics (e.g., "Hours Saved," "F*cks Given").
3.  **Tools (Product Showcase):**
    *   Card-based layout for software products.
    *   Product list: The Auto-Napper, Meeting Mutiny, Status Randomizer, Blame Generator, Coffee Break™.
4.  **The Lab (Experiments):**
    *   Grid-based showcase of "Experimental" scripts.
    *   Projects: Netflix Auto-Watcher, Pizza Router, Excuse Gen, Project "NOPE" (Abandoned).

---

## 4. Content Requirements
*   **Tone of Voice:** Sarcastic, professional-yet-lazy, humorous, technical.
*   **Key Copy:** "Lazy by Nature. Busy by Choice.", "Hard work is a bug, not a feature.", "Weaponizing laziness into peak efficiency."

---

## 5. Technical Specifications
*   **Framework:** Next.js 16 + App Router
*   **Language:** TypeScript
*   **Styling** Tailwind CSS 4
*   **Components** shadcn/ui
*   **Animation** Motion for React
*   **Advanced Motion** GSAP (only when needed)
*   **Icons** Lucide React
*   **Forms** React Hook Form + Zod(only when needed)
*   **Email** Resend
*   **Analytics** Plausible / Vercel
*   **Hosting** Vercel
*   **Images** next/image
*   **Animations Style:** Neobrutalist transitions (chunky hover offsets, no soft fades).
*   **Responsive Design:** Desktop-first (Current), Mobile-responsive (Planned).

---

## 6. Roadmap & Future Features
*   **Manifesto Page:** A full-page deep dive into the corporate mission.
*   **Mobile Version:** Adaptation of all screens for mobile devices.
*   **Interactive "Lab" Demos:** Small functional widgets for the experimental tools.
